# English Reading Flow

Obsidian 英语学习插件，**0.1.8 测试版**。

[GitHub 仓库](https://github.com/yann-su/obsidian-english-flow) · [下载 0.1.8 安装包](https://github.com/yann-su/obsidian-english-flow/releases/download/0.1.8/english-reading-flow-0.1.8.zip) · [版本说明与全部下载](https://github.com/yann-su/obsidian-english-flow/releases/tag/0.1.8)

在阅读笔记时选中英语，获取语境讲解，收藏想掌握的表达，换情境练习，再通过每日复习主动回忆。面向日常阅读、口语表达准备与写作。

0.1.8：句子和段落的卡片优先直接展示完整「中文翻译」；「意思讲解」单独折叠。可展开「怎么译出来的」，查看英文分句与中文译法及简短说明；不再用概述代替译文。默认关闭选中即讲解，选择单词后按 `⌘R` 才展开卡片，单纯选中不发起讲解、音标或发音请求。发音默认使用有道公开语音，提供英音与美音，不需要额外 API Key。请求失败时切换备用公开朗读。音频通过 Obsidian 请求下载并校验后，在本机从 Blob 播放，避免直接把远端地址交给播放器；已下载音频在本次会话中缓存。音标加载不再重建发音按钮，播放中的停止操作保持可用。

`⌘R`（Windows/Linux 为 `Ctrl+R`）、右键和命令面板仍可使用；设置中的「选中即讲解」默认关闭，默认使用快捷键手动触发。收藏和迁移练习在同一卡片内完成，表达库与每日复习通过独立命令打开。DeepSeek 默认关闭深度思考，相同选文与上下文在本次会话复用讲解。

学习数据保存在普通 Markdown 中；GitHub 同步继续由现有 **Vault GitHub Bridge** 负责。本插件不连接 GitHub、不保存 GitHub 凭据。

## 安装

需要 **Obsidian 1.11.5 或更新版本**，启用社区插件。

1. 在 [Releases](https://github.com/yann-su/obsidian-english-flow/releases/tag/0.1.8) 下载并解压 `english-reading-flow-0.1.8.zip`；GitHub 自动生成的 Source code 压缩包需要自行构建，不能直接安装。
2. 将其中的 `english-reading-flow` 文件夹放入你的笔记库配置目录：

   ```text
   你的笔记库/.obsidian/plugins/english-reading-flow/
     main.js
     manifest.json
     styles.css
   ```

   如果使用了自定义配置目录，替换 `.obsidian`。macOS 可按 `Cmd+Shift+.` 显示隐藏文件夹。

3. 重新加载 Obsidian，在「设置 → 社区插件」中启用 **English Reading Flow**。
4. 从命令面板执行 **English Reading Flow: 体验离线示例**，先完成一次不联网的学习流程。

安装包中的 README、许可证和 examples 可以保留，也可以仅安装上面三个运行文件。移动端需要分别安装插件和配置凭据；插件程序不会由笔记同步自动安装。此版本使用跨平台公开 API，桌面验证范围见 TEST_REPORT.md；iOS 和 Android 尚未完成设备验证。

源码目录还提供显式指定笔记库的安装脚本：

```sh
python3 scripts/install-local.py "/你的笔记库绝对路径"
```

脚本只复制运行文件，保留已有插件设置；如目标已存在，先备份。本脚本不自动启用插件。

## 第一次体验：不需要 API Key

1. 执行「体验离线示例」，阅读固定英语段落及讲解。
2. 在一个表达下点击「收藏并练习」。
3. 自己写一句，查看参考表达，再「保存练习」。
4. 点击「每日复习」，先作答，再揭晓并自评。
5. 点击「退出示例」，返回正式学习。

示例是固定内容，**不会自动判断你写的句子**。数据放在 `English Flow/Demo/`，不混入正式学习统计。示例数据也都是 Markdown，可以随笔记同步；不用时可以在 Obsidian 中删除整个 Demo 文件夹。

## 配置 AI

打开面板的「设置」，或执行「打开英语学习设置」。

| 设置 | 用途 |
| --- | --- |
| 学习目录 | 默认 `English Flow`，每台设备应设置为同一目录 |
| 选中即讲解 | 默认关闭，选中后按 `⌘R`；需要自动讲解时可自行开启 |
| API Base URL | 默认 `https://api.openai.com/v1`；支持兼容 Chat Completions 的服务和本机服务 |
| 模型名称 | 填写你的服务实际支持的文字模型 ID |
| DeepSeek 快速讲解 | 默认开启，使用官方接口时关闭深度思考，复杂长句需要时可关闭此项 |
| API 凭据 | 使用 Obsidian 原生凭据选择器创建或选择 API Key |
| JSON 模式 | 默认开启；不支持 `response_format` 的服务可关闭 |
| 使用旧版 token 参数 | 默认关闭；仅支持 `max_tokens` 的服务可开启 |
| 每日复习额度 | 默认 20 次作答；5～100，理解和表达分别计数 |

保存后即可使用。API Key 使用 Obsidian SecretStorage，不写入笔记或插件 `data.json`，每台设备分别配置。API 地址必须使用 HTTPS，本机 `localhost`、`127.0.0.1`、`[::1]` 可使用 HTTP；本机无鉴权服务可以不选择凭据。

接口使用 `/chat/completions`，可以填写基础地址或完整接口地址。查词、单句讲解最大输出分别为 1800、2600 个 token；段落按长度调整为 3200～7000，反馈上限 2500。兼容性依赖所选服务和模型。JSON 模式保证不了字段完整性，因此插件还会校验响应结构；错误或被截断的讲解不会保存成卡片。接口依据 [OpenAI 官方结构化输出说明](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat) 实现兼容请求。

使用 DeepSeek 时，API 地址为 `https://api.deepseek.com`，当前官方模型可填写 `deepseek-flash`。插件自动使用其支持的 `max_tokens`。快速讲解会显式发送 `thinking: {type: disabled}`；这是减少等待的默认选择，实际响应时间仍取决于网络、服务负载与内容长度。参见 [DeepSeek 思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 日常学习

### 选中内容讲解

在 Markdown **编辑模式或实时预览模式**选中一个词、短语、句子或段落，按 `⌘R` 展开卡片。单纯选中不会自动查询。也可以：

- 右键 →「讲解选中的英语」。
- 或命令面板 →「English Reading Flow: 讲解选中的英语」。
- 默认快捷键：macOS `⌘R`，Windows/Linux `Ctrl+R`。可在 Obsidian 快捷键设置中修改；用户已有的自定义快捷键优先。

PDF 或 Markdown 阅读视图：用鼠标选择文字后按 `⌘R`，或使用同一个命令。只有手动开启「选中即讲解」后才会自动展开；自动触发有短暂去抖，快速更换选区只讲解最后一次选中的内容。输入框、非英语选择、按住 Command/Ctrl/Alt 的选择不会自动查询。PDF 只发送选中的文字，不提取整份文件。收藏保留 PDF 路径，再次打开来源时跳转到该文件，暂不定位具体页码。

每次支持 1～8000 字符。讲解卡片立即在选区附近显示等待状态，返回后优先展示当前语境的意思。卡片会根据窗口边缘调整到选区上方或下方，原文不会跳转；选择单词时显示词义、用法和例句，选择句子时先展示完整中文译文，再按需展开意思讲解与分句对应翻译，并提取其中 1～3 个重点词或短语。词汇详情和句子结构按需展开。卡片内可收藏、练习，并用「返回讲解」返回同一张卡片。按 Esc、点空白处或滚动原文即可收起，卡片内部滚动不会关闭。

当前会话最多缓存 20 份讲解，缓存按选中内容、上下文和模型配置区分；重复查询不再请求，重启后清空。打开讲解时不读取学习记录。表达库与每日复习的独立命令仍可打开学习面板。

「选中即讲解」开启时，选择英语就会调用讲解服务；关闭后仅在手动讲解或「AI 反馈并保存」时调用。命中缓存时不会再次请求。讲解发送选中内容与附近少量上下文，通常不超过约 1800 字符；反馈发送目标表达、题目、参考答案和本次作答，不读取整库发送。收藏会保存表达、例句和阅读原文。未保存的练习输入在关闭卡片后不会保留；讲解缓存留在本次会话内，重启后清空。

### 音标与声音

默认向[有道词典](https://dict.youdao.com/)的公开语音入口请求音频，美音使用 type=2，英音使用 type=1。单词标题下可直接试听两种发音，不用等待音标加载，也不需要语音服务的 API Key。例句、原句与慢速按钮也默认先尝试有道。

有道无法朗读某些例句时，使用 Google 翻译公开朗读入口作为备用；这类网页语音入口不是带稳定性保证的正式开放 API。仅在点击声音按钮时发送待朗读文字，不发送原文上下文、DeepSeek Key 或其他凭据。两个公开来源均失败时，最后尝试系统英语语音并明确提示失败。

音频通过 Obsidian 的请求接口下载，检查 HTTP 状态、类型与文件头，再创建本机 Blob 地址播放。当前会话最多缓存 24 段音频，总量不超过 6 MB；重启后清空，不写入笔记库。再次试听复用缓存，切换朗读或关闭卡片会停止声音并释放临时地址。「慢速」使用 0.75 倍速度并保留音高；长文本按不超过 180 字符分段朗读。

音标仍来自 [Free Dictionary API](https://dictionaryapi.dev/)，「出处」链接对应词典页面。音标查询只发送该单词，与 DeepSeek 讲解、发音播放互不阻塞。

### 收藏表达

阅读卡片中点击「收藏表达」或「练一下 →」（会先收藏）；离线示例中可点击「收藏并练习」。卡片保留原文、笔记路径、保存时的行号；可以从表达库回到原文。原文内容移动时优先搜索完整原句；笔记改名或原句改写后，可能需要手动定位，卡片中的原句副本仍保留。

相同表达与相同中文含义会复用同一逻辑卡片；不同含义分开记忆。两台离线设备首次收藏相同表达时会保留各自独立文件，合并后作为同一个逻辑表达展示，选取最早保存的内容，不覆盖其他来源副本。AI 给出不同措辞的含义时仍可能形成不同卡片，第一版不自动做语义去重。

### 迁移练习

选择表达，先用自己的话写一句，再查看参考：

- 「保存练习」只保存回答，不调用 AI。
- 「AI 反馈并保存」获取纠错与解释，然后保存回答和反馈。
- 实际错误与可选的自然说法分别展示；参考答案不要求逐字一致。
- 请求失败时保留当前输入，可以重试或仅保存练习。

可以先口头说一遍，再写下表达。本版不录音、不做发音评分。迁移练习有目标表达提示，**不直接增加独立回忆的熟练度**。

### 每日复习

同一表达有两种独立任务：

- **理解回忆**：看到英语表达，解释它的意思。
- **表达回忆**：根据中文情境组织英语；揭晓前不展示目标表达、原句和参考答案。

必须先填写回答或选择「想不起来」才能揭晓。揭晓后按真实回忆表现选择忘记、费力、顺利或轻松；点击自评后才保存复习记录。选择「想不起来」后只能记录为忘记。系统使用自评，不把 AI 的文字评价作为记忆评分。

第一版使用透明的本地间隔规则，**不是 FSRS**：

- 新收藏的理解和表达任务立即可复习。
- 忘记：约 10 分钟后重试，重置该任务的连续成功次数。
- 费力想起：至少 1 天，之后约按原间隔的 1.2 倍增加。
- 顺利想起：首次 1 天、下次 3 天，之后按难度系数增加。
- 轻松想起：首次 4 天、下次 8 天，之后更长；最长 365 天。

额度按设备本地日期与**已同步到本地的记录**计算；跨日重置。页面展示实际作答次数、迁移次数与自评回忆结果。打开每日页面、点击「刷新记录」或安全地返回前台时重新计算到期内容；正在作答时不会自动替换题目。没有后台定时提醒。离线设备之间的每日额度无法实时协调。

## 与现有 GitHub 同步配合

学习文件结构：

```text
English Flow/
  Expressions/<逻辑卡片ID>-<捕获ID>.md
  Records/<本设备ID>/<时间>-<作答ID>.md
  Demo/
    Expressions/...
    Records/...
```

无需给英语插件设置 GitHub 地址。保持 Vault GitHub Bridge 正常运行，并确认其「排除文件夹」未排除学习目录。文件通过 Obsidian Vault API 新建，会触发现有同步插件的文件事件；也可以使用 Bridge 的「立即同步」。

表达捕获与每次作答都新增独立 Markdown 文件；不会把所有设备的记忆状态反复写入一个文件。下一次复习时间从已同步记录重放计算。其他设备同步后重新打开或刷新学习面板，就能恢复队列。已揭晓的题目若在其他设备更新过，提交前会重新核对，避免按旧状态重复排程。

卡片及记录的 YAML frontmatter 是结构化数据，正文是便于阅读的导出视图。手改正文不会修改插件读取的卡片；高级用户可以修改 frontmatter，保留 `id`、`type`、`version` 等结构字段。暂不提供批量编辑或迁移工具。删除卡片时，其历史记录仍保留，统计会忽略没有卡片的记录；多次离线捕获的同一表达如需完全删除，应删除对应的全部捕获文件。

无法解析的学习文件会保留并列在提示中，复习暂停，其他有效卡片仍可查看。请恢复正确文件后刷新；不要通过清空目录解决解析错误。

## 开发与验证

需要 Node.js 22.13+ 或 24+、npm。

```sh
npm ci
npm test
npm run build
npm run smoke
npm run package
```

产物位于 `dist/` 和 `release/`。测试使用实际打包插件及模拟 Obsidian API / HTTP 服务验证交互，不代表真实设备已通过验证。两个 Bridge 兼容测试在相邻目录有 `obsidian-github-bridge` 源码时运行；独立源码包中自动跳过，其余测试独立运行。更多结果见 `TEST_REPORT.md`。
